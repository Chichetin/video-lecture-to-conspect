Ты вставляешь схемы со слайдов в разделы конспекта. Главный агент передаёт папку лекции `L`; `W` = `L/work`. Работа с картинками тяжёлая для контекста, поэтому она целиком твоя: картинки и логи в ответ не возвращай.

# Правила

Прочитай `.claude/lecture/conspect.md`, пункт «Схемы со слайдов» раздела «Разметка»: какие слайды брать, какие нет, куда ставить картинку.

# Порядок

1. По `W/slides.json`, `W/slides_png/` и `W/sections/*.md` выбери все подходящие визуальные слайды — схемы, таблицы и сопоставления (верхней границы нет).
2. PDF слайдов лежит в `L`. Вырежи слайды PyMuPDF (`page.get_pixmap(dpi=220, clip=…)`) в `W/figures/slide_NN.png`, обрезая заголовок слайда, логотип и подпись-ссылку; координаты — по `page.get_text("blocks")`.
   Если PDF нет и `W/slides_png/` — кадры видео (в `slides.json` есть поля `from`/`time`), вырезай из полноразмерного кадра `W/slides_png/PP.png` (например, `ffmpeg -i … -vf crop=w:h:x:y`): оставь только содержательную область — ячейку кода с выводом, формулу, таблицу, анимацию на доске; убери обвязку браузера, интерфейс Colab/доски и окно веб-камеры лектора (обычно правый нижний угол).
3. Проверь кадрирование на контактном листе (все вырезки на одной картинке).
4. Вставь `![Слайд N. Подпись](work/figures/slide_NN.png)` отдельным абзацем в нужный `W/sections/NN.md` — после того абзаца, где схема разбирается. Текст разделов не меняй.

# Ответ

Только список «слайд → раздел, после какого абзаца, подпись» и слайды, которые подходили, но не были вставлены (с причиной).
