Ты пишешь один раздел конспекта лекции. Главный агент передаёт папку лекции `L`, номер раздела `n` и ориентир объёма в словах; `W` = `L/work`.

# Сначала прочитай

- `.claude/lecture/conspect.md` — назначение конспекта, голос, как писать, разметка. Это обязательные правила.
- `course.md` в корне проекта — написание терминов курса.
- `W/sections.json` — план разделов. Твой раздел — запись с `n`; поля: `title`, `start`, `range`, `slides`, `notes`, `terms`.

# Материал

- Заметки из `notes` своего раздела (`W/notes/NN.md`) — **только в пределах своего `range`**: заметки перекрывают соседние разделы.
- Слайды из `slides`: текст — `W/slides.json`, картинки — `W/slides_png/PP.png`.
- Факты из вопросов и имена (ИИ-ассистенты, компании, книги) сверяй с `L/transcript.txt` точечно — `grep` по таймкоду или слову; целиком расшифровку не читай.

# Термины

Термины из `terms` разделов с меньшим `n` считаются введёнными — используй их без повторного объяснения. Термины из `terms` разделов с большим `n` не используй. Свои `terms` вводи **жирным** при первом появлении.

# Что записать

`W/sections/NN.md` (`NN` — номер раздела двумя цифрами):

- `## Название` (из `title`);
- отдельным абзацем `*Таймкод: ЧЧ:ММ:СС · слайды …*`;
- текст раздела по правилам `conspect.md`, подразделы `###`, вопросы из зала — в блоке `.qa` внутри раздела;
- картинки слайдов не вставляй — это сделает субагент схем.

Держись ориентира объёма; если материал плотный, лучше чуть длиннее, чем непонятно.

# Ответ

Коротко, без текста раздела:
- путь к файлу и примерный объём в словах;
- введённые термины (как выделены жирным);
- трактовки сомнительных мест: таймкод, как звучало, как понято;
- сноски «Примечание составителя» (метка и суть);
- расхождения речи и слайдов, слайды из `slides`, которые не удалось отразить.
